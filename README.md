# Factor Investing in the Eurozone Equity Market

Python code supporting the bachelor thesis:
"Factor Investing in the Eurozone Equity Market: A Risk-Adjusted 
Performance Analysis of Momentum, Low Volatility, Value and Quality, 
2012–2025"

## Contents
- Data retrieval from Yahoo Finance and iShares
- Portfolio construction: Momentum and Low Volatility
- External factor premia: HML and RMW from Kenneth French dataset
- Performance metrics: Sharpe Ratio, Jensen's Alpha, Sortino Ratio,
  Maximum Drawdown, Fama-French Alpha
- Regime subperiod analysis
- All charts and tables from Chapter 5

## Requirements
Run in Google Colab. Required files:
- iShare_Holdings_only.csv (iShares EMU ETF holdings)
- iShares_Historical.csv (benchmark NAV data)
- iShares_Performance.csv (benchmark monthly returns)
- benchmark_nav.csv
- stock_prices.csv
- universe_list.csv
